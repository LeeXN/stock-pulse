Stock Pulse 是一款 Chrome 股票行情与持仓管理插件。在浏览器侧边栏查看 A 股、港股、美股、全球指数与 BTC / ETH，管理自选股和交易记录；需要深入研究时，再连接你自己的 AI 模型。

不用离开当前网页，也能看走势、记交易、核对持仓表现。

【行情与 K 线】
• 支持个股分时、日 K、周 K、月 K、年 K，结合 MA 均线、BOLL、MACD、KDJ 和成交量查看趋势。
• 点击顶部指数或币种，直接进入“市场”分组查看大图。指数与加密资产支持日、周、月、年周期，市场分组暂不提供分时。
• 向历史方向拖动图表，或点击“加载更早”，继续查看较早数据。加载后保留当前日期位置与缩放；可用历史范围取决于数据源。
• 周、月、年周期的日期带年份，跨年查看更清楚。
• 个股分时提供均价线、昨收参考线和成交量；支持交易所、本地和自定义时区。
• 全球市场区可收起为一行，图表也能单独收起，让多标的列表显示更多内容；列表提供涨跌幅、成交量和 30 日迷你走势。

【自选股与持仓】
• 搜索名称、代码或支持的 Web3 合约地址，统一关注股票与加密资产；支持分组和浏览器右键快捷加入。
• 每只持仓展示今日涨跌幅、成本、市值和累计盈亏，并可排序；加密资产采用近 24 小时口径。
• 记录买入、卖出、成交日期与时间、手续费和印花税，在图表中查看交易标记。
• 收益对比结合实际交易及费用计算，也可切换为标的价格表现，区分投资结果与市场涨跌。
• 支持多标的显示、隐藏与高亮；部分数据缺失时明确提示，不影响查看已有数据。

【批量导入与 OCR】
• 支持 CSV、TSV 和券商复制文本；先预览、核对、修改，再确认导入。
• 对日期、数量、费用和持仓进行校验，重复流水自动跳过。
• 配置支持图片输入的模型后，可用截图 OCR 辅助识别代码或交易文本；识别结果需核对后写入。

【AI 辅助研究】
• 内置“基本面速读”“技术面解读”“风险与机会”三个分析 Skill，按可用数据整理信息。
• 可以补充自己的关注点，也可导入和管理自定义 Skill。
• 支持 DeepSeek、通义千问等模型服务及 OpenAI 兼容接口，使用你自己的配置和 API Key。模型可用性与费用由对应服务商决定。

【数据与隐私】
自选股、持仓、交易记录和设置保存在浏览器本地。查询行情时，会向数据源发送标的代码等必要请求信息；主动运行 AI 或 OCR 时，相关分析上下文或截图会发送给你配置的模型服务商。插件不设置作者自有的数据收集服务器，不出售用户数据。数据备份默认不包含 API Key 和 Token。

【使用说明】
需要 Chrome 114 或更高版本。行情可能受到数据源、网络与刷新频率影响，历史范围以实际返回数据为准。AI 与 OCR 结果需要自行核对。本工具用于信息查看和个人研究，不构成投资建议或收益承诺。
